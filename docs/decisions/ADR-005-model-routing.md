# ADR-005: Sonnet للإشعارات وOpus للملخص الشهري، خلف طبقة تبديل

## الحالة
مقبول

## التاريخ
2026-11-16

## السياق
الإشعار يحتاج سرعة وتكلفة منخفضة وحجماً كبيراً. الملخص الشهري واقتراح الباقة يحتاجان تحليلاً أعمق بحجم أقل. إطار البنك المركزي للذكاء الاصطناعي يطلب تنويع الاعتماد على المورّدين.

## القرار
Claude Sonnet 5.5 لترتيب العروض وصياغة الإشعارات، وClaude Opus 5.5 للملخص الشهري وتحليل النتائج. كل الاستدعاءات تمر بطبقة واحدة تسمح بتبديل النموذج دون تغيير التطبيق، والقوالب الثابتة تعمل دون أي نموذج.

## البدائل المرفوضة
### نموذج واحد لكل المهام
- المزايا: بساطة.
- العيوب: إما تكلفة عالية للإشعارات، أو جودة أقل للتحليل.
- سبب الرفض: لا يوازن التكلفة والجودة.

## العواقب
- أي تغيير في نسخة النموذج يمر بطلب تغيير معتمد من لجنة الذكاء الاصطناعي، ويُعاد تشغيل مجموعة الاختبار الستين قبله.
