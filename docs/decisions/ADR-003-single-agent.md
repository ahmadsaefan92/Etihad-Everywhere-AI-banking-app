# ADR-003: وكيل واحد واستدعاء مستقل لكل إشعار

## الحالة
مقبول

## التاريخ
2026-11-16

## السياق
كل إشعار مهمة صغيرة مستقلة: إشارات عميل مرمّزة وأفضل 3 عروض قريبة. السياق يتسع بسهولة في استدعاء واحد.

## القرار
استدعاء واحد لـ Claude لكل إشعار، بلا سجل محادثة، بسياق ثابت أولاً (قابل للتخزين المؤقت) ومتغيّر أخيراً.

## البدائل المرفوضة
### عدة وكلاء متخصصين (مرتّب، كاتب، مراجع)
- المزايا: فصل المسؤوليات.
- العيوب: أضعاف الرموز والتكلفة وزمن الاستجابة بلا مكسب جودة مُقاس.
- سبب الرفض: مهارة multi-agent-patterns توصي بوكيل واحد عندما لا يضيق السياق.

## العواقب
- لا حاجة لضغط السياق أو إخفاء المخرجات.
- نعيد النظر عند ربط المشروع بوكيل الـ 360° في استراتيجية البنك.
